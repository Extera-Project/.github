## About Extera

**Extera Project** is an independent engineering workspace focused on building real software and exploring low-level systems.

Our projects range from Windows telemetry and kernel research to cross-platform applications, security tooling and modern web interfaces.

> **Build useful software. Understand the systems underneath it.**
